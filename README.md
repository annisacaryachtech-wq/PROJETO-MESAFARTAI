# PROJETO-MESAFARTAI

## Descrição do Projeto

O projeto MESAFARTAI tem como objetivo contribuir para o combate à fome e à insegurança alimentar, utilizando a tecnologia para apoiar iniciativas relacionadas ao acesso à alimentação.

## Objetivo de Desenvolvimento Sustentável 

O projeto está relacionado ao **ODS 2 – Fome Zero e Agricultura Sustentável**, estabelecido pela Organização das Nações Unidas (ONU), que busca acabar com a fome, alcançar a segurança alimentar, melhorar a nutrição e promover a agricultura sustentável.
