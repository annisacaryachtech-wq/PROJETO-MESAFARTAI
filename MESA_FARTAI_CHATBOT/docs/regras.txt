REGRAS DO PROJETO — MESA FARTAI

1. O chatbot deve responder em português.
2. A solução tem finalidade acadêmica e de demonstração.
3. O chatbot atende assuntos relacionados a doações, alimentos, ONGs e logística.
4. Intenções com confiança abaixo de 0,60 devem receber resposta de fallback amigável.
5. Quantidade, unidade, tipo de alimento e prazo devem ser extraídos quando aparecerem na mensagem.
6. Doações devem ser armazenadas no banco SQLite.
7. O matching deve priorizar a ONG mais próxima do doador.
8. Nenhuma informação sensível deve ser solicitada desnecessariamente.
9. Os dados usados no projeto são fictícios e servem apenas para testes.
10. O chatbot não substitui atendimento humano.



11. ETAPA 2 - MOTOR NLU:
O sistema utiliza TF-IDF para transformar as frases em vetores numéricos
e Random Forest para classificação das intenções.

O modelo Random Forest utiliza 80 árvores (n_estimators=80).

Foi definido um threshold de 0.60 (60%) para controlar a confiança
das classificações.

Quando a confiança da classificação for menor que 0.60, o sistema
deve retornar fallback.

A intenção "fora_de_escopo" também deve retornar fallback.

O motor NLU possui testes de estresse para verificar o comportamento
das classificações e do fallback.


12. ETAPA 3 - EXTRAÇÃO DE ENTIDADES E MATCHMAKING:
O arquivo src/entities.py utiliza Regex para extrair o alimento,
a quantidade e a data de validade das mensagens.

O arquivo src/matchmaking.py utiliza o algoritmo KNN para encontrar
a ONG geograficamente mais próxima do doador.

O sistema utiliza SQLite para consultar as ONGs cadastradas
e realizar o matchmaking logístico.
